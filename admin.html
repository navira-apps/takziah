Siapkan file publikasi

Unduh konfigurasi terbaru untuk mengganti file di GitHub.

1. Unduh konfigurasi

File berisi data acara, tetapi tidak memuat daftar tamu.

2. Lengkapi folder assets

Pastikan foto dan musik memakai nama yang sama dengan isian lokasi file pada tab Isi Undangan.

3. Unggah ke GitHub

Ganti config.json, unggah file media ke assets, lalu tunggu GitHub Pages memperbarui situs.

Catatan keamanan

Halaman admin pada situs statis tidak memiliki login server. Data tersimpan hanya di browser ini. Jangan menyimpan data sensitif atau token GitHub di halaman admin.
